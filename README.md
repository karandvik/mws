# mws
Данная утилита предназначена для пакетной обработки меток безопасности интернета (MotW) и написана на PowerShell, работает на системах начиная с Windows 10.

Позволяет в пакетном режиме удалять или устанавливать метки безопасности интернета (MotW) с нужной зоной блокировки.

Синтаксис и описание комманд подробно изложены в файле Readme.txt
